# wordsalad
writing prompt tool

Live site: https://wordsalad.ink/

Working notes for Claude (how Jon likes changes shipped) are in `CLAUDE.md`.

Everything lives in `index.html` (the word bank, the rules for drawing a set, and the timer). Edit that file and push to `main`, and GitHub Pages republishes the site within a minute or two.

`preview.png` is the image that shows up when someone shares the link in a text, Slack, or social post.

`apple-touch-icon.png`, `icon-192.png`, `icon-512.png` and `site.webmanifest` give the site its YAY! magnet icon when someone adds it to their phone's home screen.
